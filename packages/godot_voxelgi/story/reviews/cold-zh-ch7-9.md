# 冷听审阅：第 7、8、9 章（只听中文的听众）

问题编号：(1) 不知道指什么；(2) 术语没解释或太久以前；(3) 要重新理解句子结构；(4) 不知道为什么重要；(5) 一句里两个以上新概念；(6) 跟不上思路。
格式：章节 / 节拍 id / 句号 / 句子开头 / 问题 / 没听懂什么。

## 第 7 章 逐像素读取

整体：大部分句子一遍能听懂。第 1 到 6 章的单元格、mip、锥体、动态范围、alpha（覆盖率）都还记得，所以锥体怎么走、怎么混合基本跟得上。卡顿主要在边缘淡化、interior 和锥体半径这几处。

- 第 7 章 / c7-tag / 句 2 / 「每个物体只记录与它重叠的前两个……」 / (4) / 听到只记前两个，但不知道这限制了什么、为什么要这样限制。
- 第 7 章 / c7-tag / 句 8 / 「它们的设置存在一个缓冲区里……」 / (4)(6) / “它们”指哪两个 VoxelGI 不清楚，“最多八个共用”和前面的“前两个”是什么关系也不清楚。
- 第 7 章 / c7-space / 句 4 / 「然后，边缘淡化给……」 / (1)(6) / 先听到名字“边缘淡化”，后面三句才知道它是什么；“给光加权”没有对象。
- 第 7 章 / c7-space / 句 7 / 「但只有一个盒子时……」 / (3)(4) / “但”转折接得突然，说淡化被抵消，却没说那前面为什么要讲它。
- 第 7 章 / c7-low / 句 2 / 「这种锥体在任意一点的半径……」 / (3)(6) / “这种锥体”指哪一种不清楚；半径等于已走距离和 45 度的关系没听出来。
- 第 7 章 / c7-low / 句 3 / 「每一步前进的长度就是这个半径……」 / (3)(5) / 整句到“粗一级的 mip，纹素宽一倍”才明白；一句里同时有步长、距离加倍、mip 变粗三件事。
- 第 7 章 / c7-high / 句 5 / 「在默认质量下，四个宽锥体就够用了」 / (4) / 够用在哪方面？不知道少了什么。
- 第 7 章 / c7-spec / 句 3 / 「渲染阶段会先把粗糙度平方」 / (4) / 平方有什么作用、改变了什么，没听出来。
- 第 7 章 / c7-scale / 句 3 / 「锥体的 alpha 表示它们发现视野被填满了多少」 / (1) / “视野被填满”是什么意思，和之前的覆盖率、不透明度是不是一回事，没把握。
- 第 7 章 / c7-scale / 句 4 / 「开启 interior 设置时……」 / (1)(2) / interior 第一次出现，没解释是什么设置。
- 第 7 章 / c7-scale / 句 5 / 「所以环境光永远不会混进来」 / (1)(6) / 哪个环境光、混进什么里，没有铺垫，和上一句的因果接不上。
- 第 7 章 / c7-sources / 句 1 / 「这些是屏幕渲染阶段的代码行……缩放后的锥体」 / (1) / “缩放后的锥体”指什么。

我对本章的理解：每个像素先知道自己被哪（最多两个）VoxelGI 照亮，换算到盒子坐标，向外发四个锥体（High 时六个）读 mip，再加一个按粗糙度变宽的反射锥体，结果乘回动态范围，连同 alpha 存进缓冲区。还有一个检查永远为真的小插曲。
想问：边缘淡化到底是做什么用的？interior 是什么？alpha 在这里为什么叫“视野被填满”？半径等于已走距离是怎么来的？

## 第 8 章 保持高效

整体：结构（一次、变化时、每帧）清楚，面板讲解好懂。数字多，有几处不知道数字从哪来、为什么重要；“光照通道”与前面的“光照渲染阶段”两个叫法让我一度不确定是不是同一个东西。

- 第 8 章 / c8-map / 句 2 / 「这一切要花多少……」 / (3) / 一个没有谓语动词的问句式片段，不知道是在提问还是陈述。
- 第 8 章 / c8-map-light / 句 1 / 「光照通道只在有东西变化时运行」 / (1)(6) / 前面一直说“光照渲染阶段”，这里换成“光照通道”，不确定是不是同一个。
- 第 8 章 / c8-panel / 句 8 / 「这些时间属于这台机器」 / (4) / 为什么要强调，对我看数字有什么影响，没听出来。
- 第 8 章 / c8-cache / 句 5 / 「这三项设置是动态范围、传播系数和第二次反弹」 / (2) / “第二次反弹”什么时候成了一项可开关的设置，之前没有提过。
- 第 8 章 / c8-sparse / 句 1 / 「右边的读数统计光照通道一次更新花多少……」 / (3)(6) / “一次更新”和“一帧”各指什么，读完才勉强明白，和上一节的关系也不清楚。
- 第 8 章 / c8-sparse / 句 3 / 「光照通道真正运行时，只访问烘焙生成的单元」 / (1) / “单元”与之前的“单元格”是同一个吗。
- 第 8 章 / c8-levels / 句 3 / 「每一段是一次派发……每个工作组处理六十四个单元」 / (5)(2) / 派发和工作组两个概念同时出现，工作组为什么要提也不清楚。
- 第 8 章 / c8-levels / 句 5 / 「然后 mip 渲染阶段每次派发向上爬一个层级……」 / (6) / “屏障”先出现，下一句才解释为什么需要。
- 第 8 章 / c8-levels / 句 8 / 「开启第二次反弹时，这个房间的一次更新共需三十二次派发」 / (4) / 三十二这个数是怎么凑出来的、它说明什么，没有交代。
- 第 8 章 / c8-cones / 句 1 / 「前面这些只在变化时才运行，屏幕渲染阶段却每帧都要运行……」 / (3) / 长对比句，到句末“按像素来算”才明白要说什么。
- 第 8 章 / c8-cones / 句 3 / 「在这个盒子里，每个锥体最多走七步……」 / (6) / 第 5 章里最后一个锥体走了 11 步，这里是七步，不知道两者什么关系。
- 第 8 章 / c8-cones / 句 4 / 「每次采样读取一个预过滤的 mip……」 / (1) / “预过滤”指什么。
- 第 8 章 / c8-spec / 句 2 / 「完全粗糙的表面最多走两步……三百八十一步」 / (4) / 这两个数是怎么来的、说明什么，没交代。
- 第 8 章 / c8-spec / 句 3 / 「镜面的锥体几乎就是一条射线，所以它每次只走半个单元」 / (6) / 为什么射线变细步子反而固定成半个单元，因果没接上。
- 第 8 章 / c8-half / 句 7 / 「没有多重采样时，不透明渲染阶段用普通的双线性混合……」 / (2)(5) / 多重采样前面没提；多重采样和双线性两个条件叠在一句里。
- 第 8 章 / c8-half / 句 10 / 「边缘变得参差不齐，每次两个像素」 / (3) / “每次两个像素”不知道指什么。
- 第 8 章 / c8-half / 句 11 / 「这正是文档提醒的多边形边缘瑕疵」 / (1) / 哪份文档，“多边形边缘”是不是指上一句的参差边缘。

我对本章的理解：烘焙一次，光照阶段只在变化时跑，屏幕阶段每帧跑。面板里可以看到各阶段耗时。光照阶段只处理有内容的单元，按层级一次一次派发，阴影沿距离场大步跳。每像素只采样几次，反射锥体按粗糙度可能很贵，半分辨率只追踪四分之一像素，代价是边缘锯齿。
想问：七步、二十八次、三十二次派发、两步和三百八十一步这些数字怎么来的？为什么 High 下反射不变？“光照通道”就是前面的光照渲染阶段吗？

## 第 9 章 进入最终图像

整体：最顺的一章，回溯一个像素那节把前面串起来了。三个要点听得明白。

- 第 9 章 / c9-mix / 句 4 / 「alpha 低的地方，不透明渲染阶段会向环境自己的环境光混合……」 / (3)(1) / “向环境自己的环境光混合”绕口，“环境”是指天空还是环境光，到句末才勉强明白。
- 第 9 章 / c9-mix / 句 9 / 「不透明渲染阶段再依次给它加上环境光遮蔽、反照率……」 / (3)(4) / 只罗列四样东西，没有动词说明各自做什么，也不知道这些对 VoxelGI 的光意味着什么。
- 第 9 章 / c9-others / 句 3 / 「体积雾在它网格的每个点读取纹理的每一个 mip……」 / (1)(6) / “它网格”指谁的网格；“每一个 mip”和不用锥体的关系没听出来。

我对本章的理解：不透明阶段按 alpha 把 VoxelGI 的光与天空的光混合，交给后续的环境光处理。透明表面各自追踪锥体，雾直接读 mip。最后回溯一个像素到叶子和三角形，再总结数据、光、取舍三个要点。
想问：体积雾读每个 mip 具体是怎么读？编辑器光照视图显示一半亮度，会不会误导人？

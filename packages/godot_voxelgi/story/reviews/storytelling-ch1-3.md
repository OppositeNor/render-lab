# Storytelling review, chapters 1-3 (English)

Scope: language only (known/new/job per sentence, storytelling.md's faults, the ear rules). Facts were not checked.
Every sentence was mapped; only faulty ones are listed. "S" is the sentence number in its beat; "L" the storyboard.lam line.
Map row = known | new | job. SPLIT = the rewrite makes two or more sentences (the translation must keep one paragraph per
English sentence, so a split needs the zh-CN paragraph split too). "needs fact" = the fix needs a reason or definition the
narration lacks; no reason is invented here. Severity: H (breaks following), M, L.

## Drifting terms

- box: the VoxelGI's box vs the child cell (c2-sat); "box" also for the lab's box.
- cell / place / leaf / voxel: "places" for the field's grid, "column of cells" vs "places" (c3-field), "finest/smallest cells" vs "leaves".
- grid / cube / octree / array: the full grid (c1-box), the cube (c2-cube), the sorted array (c3-sort).
- alpha / coverage / share / weight (c2-leaf, c3-fixup, c3-bytes).
- object / mesh; collected / baked (c2-collect).
- wide cones / cones widen / grow wider (c1-room, c1-parts).
- renderer: one of three (c1-gate) vs "the renderer" (c3-sort, c3-upload).
- light: "stores light" (c1-parts) vs "no light yet" (c3-recap, c3-parents) vs emission.
- texture: the light texture vs the distance texture vs "colour texture" (c3-upload).
- skip / jump through empty space (c3-field S2 vs S10).
- nearest surface (c1-map-sdf) vs nearest leaf (c3-field).
- tables / records / buffers (c2-material, c3-bytes, c3-upload).

### Worked example (one pixel, default StandardPBR, 2x MSAA)

1. The depth pre-pass rasterises depth only into `DepthMSAA` (clear 0, stencil 0); a covered sample holds z in (0,1], 1 = near.
2. Resolve copies sample 0 to `Depth`; `DepthLinear = abs(f n / ((f - n) z - f))`.
3. Light culling and shadows run (sections 2, 6).
4. Forward runs per covered sample passing GreaterEqual (equal passes); stencil is Replaced with 0x83; it writes diffuse (light, a = -1), specular (light + emissive, a = 1), F0 and roughness, albedo*response*AO with specular occlusion in alpha, octahedral normal with alpha (1 + 2*1)/3 = 1.0.
5. DiffuseGlobalFullscreen (or its gem replacement) runs on samples with stencil & 0x80, reading albedo and normal, adding diffuse IBL.
6. Reflections run where stencil & 0x3F == 3 (0x83 & 0x3F = 3): probe stencil first changes the low bits only inside probe volumes; then global and probe passes write the reflection image.
7. SkyBox fills far samples (depth 0); ReflectionComposite adds the reflection image (ref 1, LessEqual).
8. Resolve diffuse (box), resolve specular (custom), SSS (alpha -1, so no-op), SSAO multiplies diffuse, Merge writes diffuse + specular; transparents draw over it.

### Depends on configuration

- `ENABLE_LIGHT_CULLING` 1 (0 only for QUALITY_LOW_END_TIER2); `ENABLE_DECALS` 1; `ENABLE_AREA_LIGHTS` 1 and its sub-defines.
- `o_enablePunctualLights`, `o_enableAreaLights`, `o_enableDecals` true; punctual off breaks the group order (R2.24).
- Sample count of `DepthMSAA` selects the Prepare variant (default 2x; 8x treated as 4x).
- Transparent min/max buffers are filled only by blended or tinted materials (ShaderEnable.lua:94, :99); opaque StandardPBR leaves them at clear values.

### Worked example

Camera near 0.1 m; one tile, 2x MSAA, floor ramp, nearest sample 3.0 m, farthest 11.0 m, no transparents, no sky.
1. Prepare: zNear = -3.0, zFar = -11.0 (+1 ULP). Range 8.0 m; log2(8) = 3 so 8 bins; each bin 4 mask bits = 1.0 m, each bit 0.25 m.
2. Mask bits: sample at 5.1 m, unit = 0.2625, bit 8; 7.0 m, bit 15; 3.0 m, bit 0; 11.0 m, bit 31; example mask 0x80008101.
3. Tile texel: x = asuint(-3.0), y = (asuint(-11.0..) & ~7) \| 3, z = 0x80008101, w = 0.
4. Cull: a point light (index 5) at view z -6.0 m, radius 1.9 m: passes the sphere test; range (4.1, 7.9) m, unit (0.1375, 0.6125), bits 4 and 19, objectMask 0x000FFFF0; overlap = 0x00008100 (bits 8, 15); bin masks 0xF00 (bin 2) and 0xF000 (bin 3); entry (5 << 16) \| 0x0C = 0x0005000C. (By distance it also covers bins 1 and 4 but no geometry sits there.)
5. List (8 entries): FFFE, FFFE, FFFE, 5, FFFE, FFFE, FFFE, FFFE; LightCount = 8.
6. Remap: bins 2 and 3 get [FFFE, FFFE, FFFE, 5, FFFE, FFFE, FFFE, FFFE, FFFF]; the other bins seven FFFE then FFFF; tile.w = 8.
7. Forward pixel at 5.4 m: f = (5.4 - 3)/8 = 0.3, bin = uint(0.3 * 8) = 2. Decals: FFFE, skipped; simple point and spot: skipped; point: reads 5, applies light 5, next FFFE ends; disk, capsule, quad: FFFE; polygon: FFFF ends. Light 5 is shaded once. A pixel at 3.5 m (bin 0) or 10 m (bin 7) does not evaluate it; at 6.9 m (bin 3) it does.

- Real 2x sample bit pattern of an actual frame (example mask constructed, not run).

### Worked example (one pixel, one decal)

Material: maps for base colour, metallic, roughness, normal, diffuse AO and specular cavity; other defaults. Pixel inside a decal box with decalUVW = (0.5, 0.2, 0.4).
1. Normal: map xy (0.2, -0.1) -> swapped (-0.1, 0.2); z = sqrt(1 - 0.05) = 0.9747; world = -0.1 T + 0.2 B + 0.9747 N.

3. Metallic = texture.r = 0.25 (factor ignored); albedo = base * 0.75 = (0.310, 0.234, 0.098); F0 = lerp(0.04, base, 0.25) = (0.133, 0.108, 0.063).
4. Roughness texture 0.6: A = 0.36, A2 = 0.1296; AA with variance sum 0.2: variance 0.05, kernel 0.10, A2 = 0.2296, A = 0.4792, roughnessLinear = 0.6922.

6. Decal: y flipped to -0.2, uv = (0.75, 0.40); baseMap (0.8, 0.1, 0.1, 0.9); attenuation: dot = 0.8, t = 0.5556, smoothstep 0.5830; albedoOpacity = 0.9 * 0.5830 = 0.5247.

### Worked example (one pixel, one simple point light, component defaults)

Light at (1, 0, 1.5) m; surface at origin, N = (0,0,1); V = (0, -0.7071, 0.7071); albedo 0.8, F0 0.04, roughness 0.5 (A 0.25, A2 0.0625), compensation 1, no coat.

### Depends on configuration

- Shadows: per light (`shadowEnabled` true, Cfg:67) and per material (`enableShadows` true). Only one light shadows.
- Filter None/Pcf/Esm/EsmPcf: component property; cvar overrides; default None = hard shadow softened only by the blur. Receiver-plane bias and cascade blending matter only for Pcf/EsmPcf.
- Fullscreen path forced for opaque; transparent materials use the in-shader path.
- Blur on by default; split automatic ratio 0.9; cascade correction, cascade blending, debug colouring off.

### Worked example (one pixel, 4 cascades; assumed: camera near 0.1, FOV 60 deg vertical, 16:9; not engine defaults)

1. Splits: 0.1 -> 3.014 -> 7.851 -> 23.507 -> 100 m. Radii 3.55, 9.25, 27.68, 117.76 m; texel = 2R/1024 = 0.0069, 0.018, 0.054, 0.23 m.
2. Fullscreen pass rebuilds P and N from `DepthLinear`; suppose P is 12 m from the camera.
3. For each cascade: Q = P + N * 0.00488; light space, z += 0.0015, to shadow-map coordinates.
4. Cascade 0 (R 3.55) misses P; cascade 1 (R 9.2) suppose misses; cascade 2 (R 27.7) is inside [1.5, 1022.5]: minCascade = maxCascade = 2.
5. Filter None: point sample of slice 2; stored 0.40, coord z 0.43 -> shadowed, visibility 0 (PCF would average 16 compare taps, square, clamp each comparison depth to 0.999).
6. Write 0 to the R8 target; the blur mixes neighbours weighted by depth slope (on a flat plane the weight decays by 2/3 per pixel up to radius 8).
7. Forward: v = fullscreenShadow.Load(pixel), e.g. 0.37 at a blurred edge; diffuse += albedo * saturate(N.L)/pi * diffuseResponse * 40 * v; specular += SpecularGGX * 40 * v with the unadjusted direction; then point/spot/area lights, then IBL.

### Worked example (one pixel, global sample; F0 0.04, roughness 0.5, NdotV 0.8, no probes, specular occlusion 1, exposure 0, compensation on, stencil 0x83)

1. Forward wrote F0 stored 8-bit 10/255 = 0.03922 (example uses 0.04), roughness 128/255 = 0.50196, normal octahedron, flags (IBL on, multiscatter on).
2. Global pass: 0x83 & 0x3F = 3, passes; blendWeight = 1.
3. reflectDir = reflect(-V, N), orientation identity, `GetCubemapCoords` -> (-x, z, -y).
4. mip = 0.50196 * 5 = 2.51: trilinear between mip 2 (64x64, roughness 0.4) and mip 3 (32x32, roughness 0.6).
5. BRDF at (0.8, 0.49804): O7's CPU re-run of `BRDFTextureCS` (float64) gives A = 0.8946, B = 0.00152 (the real texture comes from the GPU).
6. F0*A + B = 0.03731; compensation 1 + 0.04 (1/0.8961 - 1) = 1.0046; product 0.0375 per channel (with 8-bit F0: 0.0368).
7. specular = globalSpecular * 1.0046 * 0.0375; for sampled radiance (0.6, 0.7, 0.9): (0.0226, 0.0264, 0.0339); written per MSAA sample into the reflection image; the composite averages the 2 samples and adds the result to the specular target.
8. Diffuse side: `diffuse = albedoTarget * irradianceCubemap(dir)`; with the gem the same value times (1 - w) = 1, gated by the IBL flag.
9. With a probe, W = 0.25: global weight 0.75; the outer pass adds probe specular * 0.25 with its parallax-corrected direction and the same mip.

### Worked example (interior pixel of a StandardPBR surface, 2x MSAA, SSAO defaults, 1080p)

1. Diffuse: forward writes the same value for both samples, e.g. (0.200, 0.150, 0.100), alpha -1; hardware resolve gives (0.200, 0.150, 0.100, -1).
2. SSS pass: alpha < 0 -> (0.200, 0.150, 0.100, 0.0).
3. SSAO (half-res 960x540): 52 occluders with w = 1/(d^2 + 0.07); a corner with weighted mean cosine 0.20 gives raw = 0.8^2.2 = 0.612 (8 bits 156/255); blur and upsample give 0.70 at P. Modulate: rgb *= 0.70 -> (0.140, 0.105, 0.070), alpha 0.
4. Specular: s0 = (0.5, 0.5, 0.5), s1 = (2.0, 2.0, 2.0) (an edge highlight); brightest diagonal-neighbour luminance 1.0. s1: lumFactor = 1.5 * 1.0 / 2.0 = 0.75 -> 1.5; s0: factor 3 -> 1. log: ln 0.5 = -0.693, ln 1.5 = 0.405, mean -0.144, exp = 0.866 (unclamped would give 1.0). 5. Merge: diffuse.w = 0, no box filter; out = (1.006, 0.971, 0.936, 2.0) in HDR linear. Then transparents, then post (no bloom/DoF by default; exposure none or 2^0; ACES).

## 11. Contradictions and discrepancies between the reports

1. Multiscatter default for a StandardPBR material. O4 section 2 claim 10 and section 7 ("most likely the option stays true"), O7 section 4 and open item 5, and O3 section 4 left it open or leaned true; O4 section 8 settles it: OFF when the material does not set the property (it defaults to false and overrides the true shader-option default). Used here.
2. Whether `DiffuseGlobalFullscreen` runs. O1 (sequence, claim 8, worked example step 5) and the overview section 1 S4 list it as running with ref 128; O7 claim 7 and the overview's own section 2 and section 3 (S4) say it is disabled under the DiffuseProbeGrid gem, which the default project template includes. Resolved in favour of O7: under the default configuration `DiffuseCompositePass` runs (O1's frame order is otherwise unaffected).
3. Polygon lights with culling on: the overview (section 4.1) was unsure; O2 C21 settled they are never shaded. Group order with punctual lights off: overview section 4.2 "not tested"; O2 C22 derives it from code. Resolved, derived not run.
4. Line numbers, checked against the checkout: the overview gives `LightCullingConstants.h:15-17`, UIPass 436, CopyToSwapChain 450; O2 gives `:18-20`, O1 gives UIPass 429, CopyToSwapChain 449, PostProcess 335. The checkout confirms O1 and O2. O8 cites TransparentPass :218 and PostProcessPass :336 (pass-request lines inside a block), O1 and the overview give 217 and 335 (`"Name"` lines); both are one-off references to the same entries.
5. Directional light's default lighting-channel mask. O6 says "default mask 1 (FP.h:79)"; O5 says lights default to 31 (`LightingChannelConfiguration`, five channels) and the C++ record's 1 is overwritten by the controller. FP.h:79 does hold 1 as the struct default; the directional component controller also takes its mask from `LightingChannelConfiguration` (`DirectionalLightComponentController.cpp:541-549, :745`, cross-checked while merging, default value not re-read there), so the default is expected to be 31 and the early return of F3 is not hit by default. Treat 31 as likely, 1 as the raw struct default; the storyboard says "all five channels set" (:653).
6. Count of materials setting multiscatter: lab README.md:88 says "37 of the 39 PBR presets"; O4 section 8 says 39 `.material` files set it (the `metal_*` presets minus one file, the MacBeth illuminant, plus a test case and 4 Sponza materials). 7. 9. O1 describes the shadow-less simple-point lights and the BRDF test, O5 the transmission test; O5's finding about `ENABLE_TRANSMISSION` in Transparent_EnhancedLighting rests on an inference (R5.16), not a read.

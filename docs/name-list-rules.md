# Name list rules

Use these rules for name lists throughout Render Lab, including [Contributors](../CONTRIBUTORS.md) and
[Acknowledgements](../ACKNOWLEDGEMENTS.md). Each list must state that names are listed in alphabetical order and link
to this document. Apply the order within each section when a list has sections.

Build a sorting key for each name by concatenating these two parts, without a separator:

1. The English name of the name's language, such as `Chinese`, `English`, or `Japanese`.
2. The name's English spelling, using a romanization for a name written in another script.

Sort these keys alphabetically, ignoring letter case. Keep the person's displayed name and contact details as they
are; the key determines only their position in the list.

Use the person's stated language and English spelling when available. If the language cannot be determined and
more than one language is plausible, build the possible keys and use the one that comes first alphabetically.

The following example keys are in alphabetical order:

| Name | Language | English spelling | Sorting key |
|---|---|---|---|
| 草 | Chinese | cao | `Chinesecao` |
| Foo | English | Foo | `EnglishFoo` |
| あいうえお | Japanese | aiueo | `Japaneseaiueo` |
| 草 | Japanese | kusa | `Japanesekusa` |

For `草`, if its language is unknown, use `Chinesecao`: it comes before `Japanesekusa`. The two rows show alternative
readings of the same name, rather than two entries to add to a name list.
